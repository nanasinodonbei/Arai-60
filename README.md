# Project: Arai-60
[コーディング面接対策のために解きたいLeetCode 60問](https://1kohei1.com/leetcode/)

## Workflow
- **ブランチの作成**
  - 課題を始める前に作業用のブランチ、フォルダ、ファイル群を作成する
  - `main`（または `master`）で直接作業せず、専用のブランチに自動で切り替える
  - [TBD] スクリプト作成するか

- **課題の取り組み（step1 〜 step3）**
  - マニュアルに従ってコードを作成

- **PR作成**
  - 課題完了後に実行し、コードを GitHub へプッシュして PR（プルリクエスト）を作成する

- **Discord にレビュー依頼を投稿**
  - レビュー用チャンネルに PR のリンク等を共有してレビューを依頼する

- **レビューコメントへの対応**
  - 投稿されたフィードバックを確認し、修正を行う

- **PR のマージ**
  - レビュー完了後、`main` ブランチにコードを統合する
